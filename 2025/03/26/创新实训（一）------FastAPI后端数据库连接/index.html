创新实训（一）——FastAPI后端数据库连接

FastAPI 是一个用于构建 API 的现代、快速（高性能）的 web 框架，使用 Python 并基于标准的 Python 类型提示，尤其适合需要高吞吐量和异步支持的后端服务，有开发效率高，易于学习和维护，强大的生态支持等优点。

本次任务完成了FastAPI基础架构的构建以及FastAPI连接MySQL数据库。

项目创建

在PyCharm中新建项目的时候，可以选择创建FastAPI项目，会自动导入相关依赖并自动生成包含基础路由的 main.py，可以进行初步的FastAPI运行尝试。运行main程序后可通过默认运行端口http://127.0.0.1:8000查看运行结果，可以通过改变接口来调用不同的方法，得到不同的结果。

数据库连接

本项目使用的是MySQL数据库，因此对MySQL数据库进行连接

1. 启动MySQL服务

在终端中输入以下指令即可启动mysql服务。

2. 数据库连接

新建database.py文件，完成数据库的连接和会话管理。使用sqlalchemy和sqlmodel库创建数据库引擎和会话工厂，同时将SQLModel作为基类用于数据库模型的映射。

  • SQLAlchemy是Python SQL 工具箱和对象关系映射器，为应用程序开发人员提供了SQL 的全部功能和灵活性。它提供了一整套知名的企业级持久性模式，旨在高效，高性能地访问数据库，并适配了简单、高性能的 Pythonic 语言。

  • SQLModel基于SQLAlchemy和Pydantic构建，通过类型提示将数据库模型与 API 数据验证合二为一，大幅简化 FastAPI 项目的开发流程，兼顾类型安全和开发效率，是快速构建现代 RESTful API 的理想选择。

3. 数据模型定义

新建models.py文件，定义项目中的数据模型，使用SQLModel库创建与数据库表对应的类，目前添加了用户相关的模型。

这种实体类定义方式与之前接触过的方式都不同，它在数据模型设计中为每个功能创建独立的实体类（如 UserLogin、UserRegister 等），看似冗余，实则遵循了分层架构和单一职责原则。这种设计模式是现代 Web 开发的通用最佳实践，通过将不同场景下的用户数据模型分开定义，可以使代码更加清晰和易于维护。

4. 数据库操作定义

新建crud.py，在这个文件下会存放所有对实体类的增删改查等操作，以创建用户为例，它能够根据创建用户实体类中的属性信息，和传入的数据库会话，完成指定用户的创建操作。

5.启动程序并生成数据库表

查看数据库，发现成功创建user表，数据库连接并操作成功。
